# LensGuard 1.1.0 — emulator functional check

Date: 2026-10-04. Android 15 / API 35 Google APIs ARM64 emulator, Pixel-style profile, emulated front/rear camera. Local development-signed release build. These results describe software behavior, not hidden-camera detection accuracy.

| Check | Result | Evidence / limitation |
| --- | --- | --- |
| Build, lint, release signing | Pass | Gradle lint/test/assembleRelease; lint has no errors and 14 non-fatal dependency/localization warnings. |
| Automated regression suite | Pass | 27 tests per debug/release variant, including navigation, notes and selected-tool recreation, foreground cleanup, and bounded wireless scan lifecycle on API 28 and 35. |
| Guided Start and optional Tools | Pass | Start, Camera, Nearby and Tools render; optional sensor, magnetic, notes and sound pages remain reachable. |
| Camera preview and analysis | Pass | Camera permission prompt appears; emulated preview opens; LIVE frame counter increases. Off state disables photo and light controls. |
| Tap-to-focus, light and photo actions | Pass for software path | Actions complete without app crash; capture opens a valid image thumbnail in Android share preview. No image was sent. Emulator cannot establish physical focus quality or flashlight performance. |
| Camera foreground cleanup | Pass | Leaving Camera stops preview/use; returning requires Start camera. |
| Nearby survey | Pass for emulator | 15-second scan completes and reports the emulator's synthetic AndroidWifi access point; empty Bluetooth/service observations are shown. Real device discovery remains unverified. |
| Hidden/visible camera detection accuracy | **Not tested** | No real optical lens target, concealment, or physical Pixel 9 used. Synthetic bright-point tests are not detection-accuracy tests. |
| MacBook Pro target test with Pixel 9 | **Pending user test** | Follow the MacBook instructions in [TESTING.md](../TESTING.md). Record misses and reflective controls. |

The app has no validated camera classifier. A working preview, a highlight count or an advertised service must not be reported as a confirmed hidden camera.
