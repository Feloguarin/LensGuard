# LensGuard 2.0.0 — emulator functional check

Date: 2026-10-04. Android 15 / API 35 Google APIs ARM64 emulator with a Pixel 9 profile. The rear camera used the emulator's virtual room scene and the front camera its synthetic pattern. Debug and locally signed release builds. These results describe software behavior, not hidden-camera detection accuracy.

| Check | Result | Evidence / limitation |
| --- | --- | --- |
| Build, lint, release signing | Pass | `./gradlew lint test assembleRelease`; lint has no errors, and its only warnings are 5 notices about newer dependency versions. |
| Automated regression suite | Pass | 78 tests in each of the debug and release variants. They cover highlight reduction, preview geometry, steady tracking, the light on/off sequence with a fake flashlight, discovery parsing, leads, storage, 1.x migration, reports, and activity flows in English and Spanish on API 28 and 35. |
| Start and checklist | Pass | Places open with guidance; *Inspected* and *Needs a closer look* update the place and the inspection summary; renaming works. Linking notes to a place is covered by an activity test. |
| Camera preview and analysis | Pass | Live frames are analyzed at 1280×960. The analysis crop (944×960 at 90°) matches the preview's aspect (986×970), so rings line up with what the preview shows. |
| Highlight rings and light comparison | **Not exercised** | The virtual scene contains no small saturated points, and neither emulated camera has a flashlight. The light controls are disabled with an explanation. The comparison sequence ran only in automated tests. |
| Photo capture | Pass | A photo saved to app-private storage and appeared in the report with a thumbnail. |
| Nearby scan | Pass for emulator | The 15-second scan completed and listed the emulator's AndroidWifi access point with signal bars and freshness. ONVIF/UPnP requests were sent on the emulated Wi-Fi without errors; nothing answered. Bluetooth reported no advertisers. Saving the scan added an observation. |
| Follow signal | **Not exercised on emulator** | No Bluetooth advertisers exist in the emulator; screen flow covered by an activity test. |
| Magnetic chart | Pass | A baseline set while still; simulated field changes appeared in the chart against the dashed baseline and as the largest change since baseline. |
| PDF report | Pass | Two A4 pages: limits box, summary, checklist, observations with an upright photo, method notes and page numbers. Addresses were partly hidden. |
| Spanish UI | Pass | Per-app language set to Spanish; Start and Camera fit without clipped labels. |
| Hidden/visible camera detection accuracy | **Not tested** | No real optical target, concealment or physical Pixel 9 was used. |

The app has no validated camera classifier. A ring, a reflection result, a lead or an answering device must not be reported as a confirmed hidden camera.
